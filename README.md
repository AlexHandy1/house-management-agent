# House Management Agent

Exploring an AI agent for rental-property maintenance: take a reported issue, research a
cost estimate, find contractors, draft the messages — with a human approving anything sent.

Current work is throwaway prototyping of the agent reasoning loop. See:

- `docs/specs/maintenance-agent-slice1-full-prototype.md` — the slice 1 spec
- `docs/status_docs/` — session notes and planning
- `prototypes/` — running loop experiments (`prototypes/README.md`)

## Status

Early scaffolding. No production code yet.
